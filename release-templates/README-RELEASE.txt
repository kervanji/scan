QR Attendance - نظام تسجيل الحضور
================================

متطلبات Windows:
- Windows 10/11
- Java 17 أو أحدث (https://adoptium.net)
- كاميرا ويب

التشغيل:
- Windows: انقر مرتين على "Start Attendance.bat"

التحديث التلقائي:
- يفحص التحديثات من GitHub تلقائياً
- من لوحة الإدارة → التحديثات يمكنك فحص يدوي

البيانات محفوظة في:
- C:\Users\<USER>\AttendanceSystem\
