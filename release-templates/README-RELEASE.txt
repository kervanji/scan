Murakib Attendance - نظام تسجيل الحضور
========================================

متطلبات Windows:
- Windows 10/11 (64-bit)
- كاميرا ويب
- Java 17+ مطلوب فقط إذا شغّلت البرنامج عبر ملف .bat (حمّله من https://adoptium.net)

التشغيل:
- الطريقة الأسهل: انقر مرتين على "Murakib Attendance.exe"
- بديل: انقر مرتين على "Start Attendance.bat"

التحديث التلقائي:
- يفحص التحديثات من GitHub تلقائياً عند التشغيل
- من لوحة الإدارة → التحديثات يمكنك فحص يدوي

البيانات محفوظة في:
- C:\Users\<USER>\AttendanceSystem\

PIN الإدارة الافتراضي: 1234
(يُفضّل تغييره من لوحة الإدارة → الإعدادات)
